# JARVIS 仓库技能

配套预览 APK：`app.jarvis.assistant` 0.2.8-preview.8，版本代码 17 或更高的兼容版本。

在 App 的「设置 → 仓库技能」填写本目录 `skills-v1.json` 的 GitHub 文件地址或 Raw HTTPS 地址，点击检查并下载更新。查看执行步骤后开启所需技能。下次更新继续使用同一地址，不需要重下语音模型。

本批包含小声一点、大声一点、轻声听歌、微信扫一扫和支付宝扫一扫。轻声听歌会先把媒体音量设为约 20%，再请求酷狗恢复播放；不是指定歌曲搜索。

新技能或有变化的技能默认关闭，未改变的技能保留开关。千问与 DeepSeek 按语义选择已启用技能，本地模式支持配置中的精确示例。参数与步骤是数据，不下载可执行代码。新增手机端尚未实现的系统接口仍需更新 APK。

## 维护配置

- `schema` 固定为 1；修改内容时提高 `revision`，不要原地改变同版本内容。
- `min_app_version` 为 APK 版本代码，不是版本名称。
- 每条技能仅含 `id`、`title`、`examples`、`steps`；每步仅含 `tool`、`arguments`。
- 本版可组合 `control_volume`、`control_kugou`、`open_app`、`get_alarms`、`open_wechat_scan`、`open_alipay_scan`。
- 每项最多 6 步；打开应用、酷狗等界面交接必须位于最后一步。失败或取消会停止后续步骤，已经完成的动作不会撤回。
- 单文件最多 128 KB，最多 32 项，每项最多 8 条触发示例；禁止未知字段、重复 JSON 键、脚本、递归技能。
- 配置不放 API Key、个人地址、账号或诊断内容。此目录独立于已发布的模型资源，不修改模型 ZIP 和校验值。

配置格式与存储行为已通过配套代码测试；一加 15 上的音量、酷狗交接和云端语义选择仍需真机验证。本目录不是新的正式 APK 发布。
